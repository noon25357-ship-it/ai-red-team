# ai-red-team

**Before you build it, try to kill it.**

سكيل لـ Claude يحوّله إلى فريق Red Team كامل — سبع شخصيات مهمتها الوحيدة
مهاجمة فكرتك أو مشروعك أو مخرجك قبل أن تضيّع وقتك أو مالك في بنائه.

لا يمدح. لا يساعدك على التنفيذ المباشر. يحاول يهزمك، ثم يعطيك تقريرًا فيه
قرار واضح.

---

## لمن يناسب هذا السكيل؟

- مؤسس يفكر يبني SaaS أو منتج جديد قبل ما يصرف عليه وقت أو فريق.
- شخص جاهز يطلق متجر إلكتروني أو صفحة هبوط ويبي رأي صريح قبل الإطلاق.
- كاتب PRD يبي يعرف وين الثغرات قبل ما يوصل للمطورين.
- مسوّق أو صاحب عرض خدمة يبي يعرف وين الرسالة ضعيفة.
- أي شخص يكتب Prompt معقّد ويبي يتأكد ما فيه تعارضات أو ثغرات قبل الاعتماد
  عليه.

**لا يناسب** من يبي مجاملة، أو من يبي أحد يكتب له الكود مباشرة، أو من يبي
خطة تنفيذ جاهزة من أول رسالة.

---

## وش يسوي؟

يشغّل عملية هجوم منظمة من سبع زوايا ثابتة على أي مدخل تعطيه إياه:

| الشخصية | سؤالها الثابت |
|---|---|
| العميل | ليش أشتري؟ ليش ما أشتري؟ |
| المستثمر | ليش ما أستثمر؟ |
| المنافس | شلون أتغلب عليك خلال أسبوع؟ |
| المسوّق | وين الرسالة ضعيفة؟ |
| المطوّر | وين التعقيد المخفي؟ |
| المشغّل | وش بيكلّفني تشغيله يوميًا؟ |
| المخاطر والتنظيم | وش المخاطر القانونية أو الخصوصية؟ |

بعدها الشخصيات تهاجم بعضها (جولة تعارضات)، ثم يطلع تقرير نهائي فيه:

- قرار واحد صريح: `BUILD` / `BUILD AFTER CHANGES` / `TEST FIRST` /
  `DO NOT BUILD` / `INSUFFICIENT EVIDENCE`
- درجة ثقة رقمية (0–100)
- أكبر المخاطر مرتبة حسب الخطورة
- Kill Tests رخيصة تقدر تجرّبها بسرعة قبل أي قرار بناء
- نسخة أقوى من نفس فكرتك بعد معالجة أضعف نقاطها

## وش ما يسويه؟

- ما يكتب كود، وما ينفّذ المشروع.
- ما يعطيك خطة تنفيذ أو برومبت بناء جاهز إلا إذا طلبت ذلك صراحة **بعد**
  ما تشوف التقرير.
- ما يخترع أرقام سوق أو منافسين أو تكاليف — إذا المعلومة ناقصة يقول لك
  إنها ناقصة، وما يكمّلها من عنده.
- ما يقتل فكرتك لمجرد إنها موجودة بالسوق أو فيها منافسين.
- ما يقدّم استشارة قانونية أو مالية معتمدة — فقط يوضّح المخاطر التي تحتاج
  مختص.

---

## Quick vs Full

**Quick Red Team** — للأفكار القصيرة والاستخدام السريع. يعطيك القرار + أكبر
5 مخاطر + 3 Kill Tests + خطوة واحدة تسويها الحين.

**Full Red Team** — للـPRD والنصوص الطويلة وصفحات الهبوط الكاملة أو أي وقت
تبي تحليل عميق. يشغّل كل الشخصيات السبع، جولة الهجوم المتبادل، وجدول مخاطر
كامل.

إذا ما حددت الوضع، السكيل يختار تلقائيًا حسب طول وتعقيد المدخل — أو يسألك
مباشرة لو كان الموقف غير واضح.

## طريقة التثبيت

هذا مجلد Skill قياسي. انسخ مجلد `ai-red-team/` كامل إلى مسار الـ Skills عندك
(محليًا أو ضمن مشروعك)، بحيث يحتوي على `SKILL.md` في الجذر. Claude Code
ومنصات Claude الأخرى التي تدعم Skills تكتشفه تلقائيًا من اسمه ووصفه في
الـ frontmatter.

لا حاجة لأي تثبيت إضافي أو اعتماديات — السكيل نص تعليمات فقط، بدون سكربتات
تنفيذية.

---

## طريقة الاستخدام

اكتب طلبك مباشرة، والسكيل يتفعّل تلقائيًا إذا كان الطلب يطابق وصفه. تقدر
أيضًا تطلبه صراحة:

```
راجع لي هالفكرة بوضع Quick:
[الصق فكرتك هنا]
```

```
سوّي لي Full Red Team على هذا الـ PRD:
[الصق PRD كامل هنا]
```

راجع [QUICK-START.md](QUICK-START.md) لصيغ الاستدعاء الكاملة، و
[EXAMPLES.md](EXAMPLES.md) لأمثلة كاملة على مدخلات ومخرجات حقيقية.

## مثال مختصر

**المدخل:** "أبي أسوي تطبيق يقترح وجبات صحية حسب مزاجك اليوم."

**جزء من المخرج (Quick):**

```
القرار: TEST FIRST
درجة الثقة: 40/100
أكبر خطر: ما فيه دليل إن "المزاج" فعليًا يغيّر قرار الأكل عند المستخدم
أكثر من عوامل أبسط (الوقت، الميزانية، الجوع) — الفرضية الأساسية غير مختبرة.
```

هذا مثال مختصر فقط. راجع [EXAMPLES.md](EXAMPLES.md) للتقرير الكامل.

## تنبيه مهم

نتائج هذا السكيل **ليست استشارة قانونية أو مالية أو استثمارية معتمدة**. هي
تحليل نقدي منظم يساعدك تفكر بزوايا قد تكون غفلت عنها — القرار النهائي وأي
التزام قانوني أو مالي يبقى مسؤوليتك، ويُنصح بمراجعة مختص عند وجود مخاطر
جوهرية.
